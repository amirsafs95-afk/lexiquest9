# LexiQuest 9 — نسخهٔ استاتیک رایگان

این پوشه نسخه‌ای مستقل از LexiQuest 9 است که برای انتشار رایگان روی **GitHub Pages** آماده شده است. ظاهر آن در لایهٔ `fantasy.css` با تم فانتزی و بازی‌محور بازطراحی شده، اما متن‌ها، داده‌های آموزشی و منطق برنامه حفظ شده‌اند. این نسخه به Node.js، SQLite، سرور، API خصوصی یا فایل `.env` نیاز ندارد.

## اجرای محلی

برای اجرای درست، فایل `index.html` را با دوبار کلیک باز نکن؛ مرورگر ممکن است به‌دلیل محدودیت `file://` اجازهٔ خواندن `static-data.json` را ندهد.

در ویندوز، در همین پوشه PowerShell را باز کن و اجرا کن:

```powershell
py -m http.server 8000
```

سپس در مرورگر این نشانی را باز کن:

```text
http://localhost:8000
```

برای توقف سرور محلی `Ctrl + C` را بزن.

برای اعتبارسنجی فایل‌ها در صورت نصب Node.js نسخهٔ ۱۸ یا جدیدتر، این دو دستور را اجرا کن:

```powershell
node .\verify-static.mjs
node .\tests\static-smoke-test.cjs
```

## انتشار رایگان با GitHub Pages

۱. وارد حساب GitHub خودت شو و یک مخزن جدید بساز؛ مثلاً `lexiquest9`. برای فعال‌بودن GitHub Pages، مخزن را Public انتخاب کن.

۲. محتویات همین پوشه را مستقیماً در ریشهٔ مخزن قرار بده؛ یعنی `index.html` باید در ریشه باشد، نه در یک زیرپوشه. فایل‌های زیر را همگی بارگذاری کن:

- `index.html`
- `static-app.js`
- `static-data.json`
- `styles.css`
- `static.css`
- `fantasy.css`
- `sw.js`
- `manifest.webmanifest`
- `icon.svg`
- `.nojekyll`

۳. در GitHub به مسیر **Settings → Pages** برو.

۴. در بخش Build and deployment، گزینهٔ **Deploy from a branch** را انتخاب کن؛ Branch را روی `main` و پوشه را روی `/(root)` قرار بده و Save را بزن.

۵. پس از پایان انتشار، نشانی سایت در همان صفحه نمایش داده می‌شود و معمولاً به این شکل است:

```text
https://USERNAME.github.io/lexiquest9/
```

به‌جای `USERNAME` نام کاربری GitHub و به‌جای `lexiquest9` نام مخزن خودت را قرار بده.

## محدودیت‌های ذاتی نسخهٔ استاتیک

این نسخه سرور و پایگاه داده ندارد. بنابراین ثبت‌نام و ورود واقعی، همگام‌سازی بین دستگاه‌ها، پنل مدیریت سروری، ارسال ایمیل، هوش مصنوعی آنلاین و ذخیره‌سازی ابری در آن فعال نیستند. اطلاعات پیشرفت در `localStorage` مرورگر همان دستگاه ثبت می‌شود. برای انتقال اطلاعات از دستگاهی به دستگاه دیگر از پشتیبان JSON استفاده کن.

گفتار ماشینی برای شنیدن واژه‌ها به پشتیبانی مرورگر و صدای نصب‌شده روی دستگاه وابسته است. نصب‌پذیری و استفادهٔ آفلاین به HTTPS و پشتیبانی مرورگر وابسته‌اند؛ روی GitHub Pages اتصال HTTPS فراهم می‌شود.

## نکات امنیتی و حریم خصوصی

- محتوای این پوشه برای مخزن عمومی آماده شده و عمداً فایل‌های سرور، SQLite، حساب‌ها، نشست‌ها، پشتیبان‌های دیتابیس و `.env` را ندارد.
- هیچ API key یا رمز عبوری در فایل‌های سایت قرار نده.
- فایل پشتیبان JSON ممکن است نام نمایشی و تاریخچهٔ مطالعه داشته باشد؛ آن را در مخزن عمومی GitHub بارگذاری نکن.
- تمام داده‌های پیشرفت در همان مرورگر و روی همان دستگاه می‌ماند؛ پاک‌کردن اطلاعات سایت در مرورگر می‌تواند آن‌ها را حذف کند.

## منبع داده و شمارش

داده‌های آموزشی از ماژول‌های پروژهٔ ارائه‌شده استخراج شده‌اند. واژگان تکراری در سطح هر درس، مطابق منطق seed دیتابیس، حذف شده‌اند. اصلاحات فایل `irregular-examples.js` بر ۵۹ فعل اعمال شده‌اند. شمارش‌ها در `static-data.json` نیز بررسی شده‌اند.

این خروجی صحت‌سنجی مستقل تمام محتوای آموزشی در برابر نسخهٔ چاپی کتاب را ادعا نمی‌کند؛ مستندات منبع خود پروژه نیز بخشی از تلفظ‌ها، توضیحات و مثال‌ها را محتوای کمکی معرفی کرده‌اند.
